# Military Asset Management System (MAMS) Prototype

## Overview
A web application prototype built with React (Vite) and Node.js (Express) designed to manage military installation assets, track stock metrics, log purchases, dispatch transfers, and assign equipment to personnel.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js, JSON Web Tokens (JWT)

## How to Run

### 1. Start Backend Server
```bash
cd backend
npm install
node server.js
